# 歌颂之丘

本地化补丁发布站。打开 index.html，或运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 http://127.0.0.1:8765/。

## 当前形态：黑白灰复古资料站

参考「三重奏发布」的窗口化构成（左侧按钮列 + 中间窗口 + 底部标签条），做成本站的普通标签页切换版，
**不是聊天应用**。只用黑、白与中间灰阶，不引用拆包图片。

- 左侧固定 **7 个主标签页**，窗口底部固定 **3 个子标签页**（Home / Download / Staff）。
- 主标签、子标签统一为**英文在上、中文在下**；**不显示任何 01 / 02 / 03 编号**。
- 切换主标签时保留当前子页；路由为 `#系列/子页`，如 `#at2/download`。
- **不再显示面包屑**：当前所处位置由窗口标题栏（`系列 / 子页`）和底部子标签的选中态共同表达，
  页面内只保留标题，避免同一信息在一屏里重复三遍。

### 排版与配色规则

- **黑 + 白 + 灰阶**，无彩色。层级由三层叠加表达，不靠纯黑纯白的硬对比：
  1. **面色差**：页面画布 `#e8e8e8` → 窗口面 `#fff` → 区块面 `#f5f5f5` → 交互面 `#ededed`；
  2. **描边深浅**：窗口外框 `#a6a6a6`、结构线 `#c4c4c4`、行分隔 `#e2e2e2`、发丝线 `#ededed`；
  3. **字重与字色**：标题 `#191919`、正文 `#333`、次要 `#4b4b4b`、说明 `#767676`、占位 `#a3a3a3`。
- 深色块统一用 `#2c2c2c`（标题栏）/ `#3a3a3a`（选中态），不用纯黑，避免与白底对撞。
- 选中态：主标签为深灰底白字块；子标签为**白底 + 顶部 3px 深灰条**（下划线式），两者形态区分开。
- 小节标题 `h2` 为浅灰底 + 左侧 3px 深灰竖条，长列表隔行浅灰底，便于扫读。
- 字号阶梯：页面标题 21px，正文 15px/1.85，界面标签 10–11px 等宽体。
- 主标签副标题限制两行（`-webkit-line-clamp:2`），避免标签栏高度参差。
- 断点：1100 / 820 / 520px。820px 以下左侧栏转为顶部横向标签条，窗口仍占满剩余高度。

### 滚动行为

- `html, body { height:100%; overflow:hidden }` —— **整页不滚动**。
- 外壳为三行 grid（顶栏 / 控制台 / 页脚），窗口 `min-height:0` + `flex:1`，
  只有 `.panel-body` 内部 `overflow-y:auto` 上下滚动；标题栏、底部子标签、页脚始终固定可见。
- 切换标签时正文滚动位置复位到顶部。

### 文案修改入口

**`index.html` 只是页面骨架，不要直接在空的 `section#page` 中写正文。**

| 要修改的内容 | 文件与位置 |
| --- | --- |
| 作品名称、副标题、尚未整理作品的简介 | `js/content.js` → `SITE.series` |
| 底部三个按钮的中英文 | `js/content.js` → `SUBPAGES` |
| 尚未整理页面的提示、外部链接页标题 | `js/content.js` → `SITE_TEXT` |
| Web 页链接名称与网址 | `js/content.js` → `WEB_LINKS` |
| AT1 / AT2 正文、下载地址、更新记录、人员名单 | `js/at1.js` |
| 各作品的页脚 | `js/content.js` → 各作品的 `footer` |
| 颜色、字号、间距与手机布局 | `css/style.css` |

`js/main.js` 是渲染与交互程序，通常不需要修改。修改文案时保留 `id`、引号、逗号和括号。

### 文件

- `index.html` — 页面骨架、文案修改导航和页脚。
- `css/style.css` — 黑白灰配色、机械风格、响应式布局。
- `js/content.js` — 通用文案、作品目录、子页按钮与外部链接。
- `js/main.js` — 页面渲染、路由、手机菜单与键盘导航。
- `js/at1.js` — AT1 / AT2 的页面正文与数据。
- `_backup/` — 改版前的旧文件备份。
