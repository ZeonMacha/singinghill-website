# 歌颂之丘

本地化补丁发布站。直接打开 `index.html`，或运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 http://127.0.0.1:8765/。

## 当前形态：机械 HUD 结构 + 柔焦磨砂背景与分作主题色

在保留固定机械切角 HUD 骨架（`css/style.css` 不做结构改动）的基础上，通过独立的主题叠加层（`css/theme.css` + `js/theme.js`）为 **Ar tonelico I / II / III** 提供差异化柔焦磨砂背景与深色系主题配色，并附带可视化**内置区域调色板**（`css/tuner.css` + `js/tuner.js`）以便实时微调每个区域的色彩与磨砂质感。

### 结构

```
┌──────────────┬─────────────────────────────────────────────────────┐
│ AR TONELICO  │ ▮ Ar tonelico / Home                                │ ← 切角机械顶栏 + HUD 连接导线
│ 于世界终末…   ├─────────────────────────────────────────────────────┤
│──────────────│  Ar tonelico 本地化补丁                             │
│ AR TONELICO II│                                                    │
│ 回响于世间…   │        ← 只有这块区域上下滚动 →                      │
│──────────────│                                                    │
│ …            ├─────────────────────────────────────────────────────┤
│              │   HOME      │   DOWNLOAD   │    STAFF              │ ← 独立底部子标签模块
│              │ 主页 / 特性  │ 下载 / 补丁教程│   制作人员            │
└──────────────┴─────────────────────────────────────────────────────┘
                        页脚占位符（居中）
```

- 左侧固定 **7 个主标签页**，底部固定 **3 个子标签页**（Home / Download / Staff）。
- 切换主标签时路由更新为 `#系列/子页`，如 `#at1/download`。
- **磨砂与三作背景区分**：
  - `AT1` 使用 `images/at1.jpg`（深紫靛主题色系）；
  - `AT2` 使用 `images/at2.jpg`（深海青蓝主题色系）；
  - `AT3` 使用 `images/at3.jpg`（深暮紫主题色系）；
  - `Ciel nosurge`、`Ar nosurge`、`Web` 自动回退为中性灰雾磨砂底。
- 左侧作品按钮、中央主窗口与底部子页按钮均通过 `js/theme.js` 将 SVG 多边形切角轮廓实时同步为毛玻璃层 `clip-path`。

### 滚动行为

- `html, body { height:100%; overflow:hidden }` —— **整页不滚动**。
- 只有 `.panel-body` 内部 `overflow-y:auto` 上下滚动，配右侧自定义机械游标滚动条；左侧栏、标题栏、底部子标签与页脚始终固定可见。
- 切换标签时正文滚动位置复位到顶部。

## 内置区域调色板使用指南

打开页面后，右上角默认显示悬浮的 **「区域调色板」**（由 `css/tuner.css` 与 `js/tuner.js` 提供），可直接对站内各个区域实时调色并预览。

### 1. 面板定位与显示控制

- **自由拖动**：按住调色板顶部标题栏空白处可任意拖动位置，避免遮挡正在观察的区域。
- **左右停靠**：点击顶栏 **「靠左 / 靠右」** 可一键将面板切换至屏幕左侧或右侧。
- **收起与快捷键**：点击顶栏 **「收起 / 展开」** 或按下键盘 **`Alt + T`**，可随时收起调色板查看完整无遮挡画面。

### 2. 按作品独立调色与自动保存

- 调色板顶部的 **`AT1` / `AT2` / `AT3` / `其他页`** 按钮与网页左侧作品导航双向联动：
  - 点击任一按钮会自动切换到对应作品页面，并加载该作品专属的调色参数；
  - `其他页` 控制尚未配置专属背景图的通用页面（Ciel nosurge / Ar nosurge / Web）。
- 所有颜色、透明度与模糊度改动都会**实时生效**，并自动保存在当前浏览器的 `localStorage`（键名 `singinghill_color_tuner_v1`），刷新页面不会丢失。

### 3. 四大可调区域说明

每一项颜色均支持**点击色块弹出取色器/吸管**，也支持在右侧输入框直接粘贴或键入 `#RRGGBB` 十六进制色号；带透明度的项目右侧配有 `0.00–1.00` 浓度滑杆。

1. **1. 背景与磨砂柔焦**
   - **画布垫底色**：最底层画布背景色（同时同步到移动端浏览器地址栏 `theme-color`）。
   - **背景图柔焦半径 / 饱和度 / 不透明度**：调节 `images/at1~3.jpg` 的高斯模糊程度（`0–32px`，扩边防漏白自动跟随计算）、色彩饱和度与透出比例。
   - **雾纱中心色 / 暗角边缘色与浓度**：控制覆盖在柔焦背景图上的径向氛围薄纱，用于提亮局部或压暗四周暗角。
   - **喷砂颗粒浓度**：控制微细亚克力噪点纹理强度。
2. **2. 中央主窗与机械线框**
   - **一键主窗明暗**：提供 **「柔雾浅底主窗」** 与 **「烟熏黑底主窗」** 两个快捷预设，一键联动切换主窗底色、内部分割线与正文字色明暗，切换后仍可继续逐项细调。
   - **主窗底色 / 透明度 & 毛玻璃模糊**：调节中央正文大框的底色黑度/明度、透景比例与 `backdrop-filter` 模糊半径。
   - **主窗外框与装甲色**：控制中央窗口的 `2px` 轮廓线、右上阶梯装甲条、左侧护板、右下实心三角、左下直角标及标题前竖标。
   - **内容强调与按钮色**：控制正文内 `h2` 小节左竖条、提示框左竖条、列表方点及网盘下载大按钮（按钮文字颜色会根据深浅自动切换黑白对比）。
   - **左上 HUD 连接导线色 / 右侧滚动条滑块色**：分别独立控制连接折线与自定义滚动条游标颜色。
   - **内部条带与卡片底色 / 内部分割线色**：控制 `h2` 渐变底条、隔行列表底色、下载卡片底色与各级横线浓度。
3. **3. 左侧与底部按钮框**
   - **未选中框底色 / 黑度 & 毛玻璃模糊**：控制左侧未选中作品框、底部未选中子标签框及手机展开抽屉的毛玻璃底色与黑度。
   - **未选中描边与侧脊 / 未选中字色（主 / 副）**：分别调节未选中按钮的外框线、左侧竖条与中英文字色。
   - **选中框渐变（起 / 终 / 浓）**：左侧两个色块分别为 135° 渐变的起始色与结束色（设为相同色号即为纯色），右侧滑杆控制不透明度。
   - **选中高亮（外框 / 侧脊） & 选中字色（主 / 副）**：调节当前激活按钮的高亮切角描边、发光侧脊与文字颜色。
4. **4. 正文与页脚文字色**（默认折叠，点击展开）
   - 分别调节主标题与重点字、正文段落字、次要说明与注音字，以及底部页脚字色（自动匹配深浅描边阴影）。

### 4. 同步、备份与正式定稿上线流程

- **同步模糊/透明度**：在某一页调好满意的柔焦半径、喷砂浓度与各框透明度后，点击底部 **「同步模糊/透明度」** 即可将这些质感参数一键同步到其余所有页面，而不会覆盖各页独立的主题色。
- **重置本页 / 全重置**：恢复当前作品或全部页面的初始默认配色。
- **复制参数 / 导入参数**：点击 **「复制参数」** 会将四套完整配色导出为 JSON 复制到剪贴板，便于跨设备保存或通过 **「导入参数」** 粘贴恢复。
- **定稿固化并隐藏调色板（正式发布时）**：
  1. 调色满意后，点击调色板右下角 **「导出 theme.css」** 下载完整样式表；
  2. 用下载得到的 `theme.css` 直接覆盖项目中的 `css/theme.css`；
  3. 打开 `index.html`，注释或删去调色板相关的两行引用即可收起工具窗：
     ```html
     <!-- <link rel="stylesheet" href="css/tuner.css?v=1" /> -->
     <!-- <script src="js/tuner.js?v=2"></script> -->
     ```

## 文案与文件索引

**`index.html` 只是页面骨架，不要直接在空的 `section#page` 中写正文。**

| 要修改的内容 | 文件与位置 |
| --- | --- |
| 作品名称、副标题、尚未整理作品的简介 | `js/content.js` → `SITE.series` |
| 底部三个按钮的中英文 | `js/content.js` → `SUBPAGES` |
| 尚未整理页面的提示、外部链接页标题 | `js/content.js` → `SITE_TEXT` |
| Web 页链接名称与网址 | `js/content.js` → `WEB_LINKS` |
| AT1 / AT2 正文、下载地址、更新记录、人员名单 | `js/at1.js` |
| 各作品的页脚 | `js/content.js` → 各作品的 `footer` |
| 基础机械 HUD 结构、字号、间距与响应式断点（已固定） | `css/style.css` |
| 磨砂背景层与 AT1 / AT2 / AT3 主题配色 | `css/theme.css`、`js/theme.js` |
| 内置实时区域调色板 | `css/tuner.css`、`js/tuner.js` |
