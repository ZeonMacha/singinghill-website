# 歌颂之丘

本地化补丁发布站。直接打开 `index.html`，或运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 http://127.0.0.1:8765/。

## 当前形态：机械 HUD 结构 + 柔焦磨砂背景 + 分层外框与分作主题色

在保留固定机械切角 HUD 骨架（`css/style.css` 不做结构改动）的基础上，通过独立的主题叠加层（`css/theme.css` + `js/theme.js`）为 **Ar tonelico I / II / III** 提供差异化柔焦磨砂背景、烟熏毛玻璃与深色系主题配色，并通过外框分层体系拉开主次层次：

- **中央正文主窗（核心承载层）**：纯黑外侧防融边护边 + 双层纯黑下沉阴影（近距接触暗影 + 远距下坠长影）+ `2px` 极净单线框（0 外散发光、不向内部毛玻璃渗暗）。
- **激活焦点回路（当前作品 Tab + HUD 导线 + 当前子页 Pill）**：粗黑护边、抬升下沉阴影与**仅向框内缘微收**的高亮光感；连接导线自带黑护边衬底与垂直投影。
- **待命导航栏（未选中作品与子页按钮）**：细黑护边 + 浅接触影 + 0 发光的克制单线，明确退居二线。
- 隐藏了底部按钮多余的内圈复线，保持全站纯粹利落的单线切角视觉。

- 左侧固定 **7 个主标签页**，底部固定 **3 个子标签页**（Home / Download / Staff）。
- 切换主标签时路由更新为 `#系列/子页`，如 `#at1/download`。
- **磨砂与三作背景区分**：
  - `AT1` 使用 `images/at1.jpg`（深紫靛主题色系）；
  - `AT2` 使用 `images/at2.jpg`（深海青蓝主题色系）；
  - `AT3` 使用 `images/at3.jpg`（深暮紫主题色系）；
  - `Ciel nosurge`、`Ar nosurge`、`Web` 自动回退为中性灰雾磨砂底。
- 左侧作品按钮、中央主窗口与底部子页按钮均通过 `js/theme.js` 将 SVG 多边形切角轮廓实时同步为毛玻璃层 `clip-path`，并自动计算外扩护边与外侧挖空投影遮罩。

### 滚动行为

- `html, body { height:100%; overflow:hidden }` —— **整页不滚动**。
- 只有 `.panel-body` 内部 `overflow-y:auto` 上下滚动，配右侧自定义机械游标滚动条；左侧栏、标题栏、底部子标签与页脚始终固定可见。
- 切换标签时正文滚动位置复位到顶部。

## 独立区域调色插件使用指南（与 HTML 完全分离）

调色窗口已从 `index.html` 中彻底摘出，作为独立的本地开发插件存放在 `tools/tuner/`，**正常发布与打开 `index.html` 时不会加载任何调色工具**。

### 1. 启动插件

- **Windows**：直接双击根目录的 **`start-tuner.bat`**（自动优先使用 Python，若未安装 Python 会自动切换 Windows 内置 PowerShell 启动本地服务，并弹出浏览器预览）。
- **Linux / macOS / 命令行**：运行 `python3 tools/tuner/server.py` 后访问终端提示的 `http://127.0.0.1:<端口>/`。

插件会在本地服务器内存流中自动将调色板挂载到 `index.html`，磁盘上的 `index.html` 始终保持干净。

### 2. 面板定位与按作品调色

- **自由拖动 / 靠左靠右 / 快捷键**：按住顶部标题栏可拖动位置；点击 **「靠左 / 靠右」** 切换停靠侧；点击 **「收起 / 展开」** 或按 **`Alt + T`** 随时隐藏查看无遮挡全屏效果。
- **按作品独立调色**：顶部 **`AT1` / `AT2` / `AT3` / `其他页`** 按钮与网页左侧导航双向联动，所有改动实时生效并自动保存至浏览器 `localStorage`（键名 `singinghill_color_tuner_v2`）。

### 3. 四大可调区域说明

1. **1. 背景与磨砂柔焦**：画布垫底色、背景图柔焦半径/饱和度/不透明度、径向雾纱中心与暗角边缘、喷砂颗粒浓度。
2. **2. 中央主窗、护边与下沉影**：
   - 提供 **「烟熏黑底主窗」** 与 **「柔雾浅底主窗」** 快捷预设；
   - 可调主窗底色/透明度/模糊度、外框装甲色、强调与下载按钮色、导线色、滚动条滑块色、卡片底色与分割线浓度；
   - 新增 **外框防融边护边与下沉影** 参数：外护边色与浓度、护边线宽、主窗下沉长影深度/浓度、近距接触影浓度、左上连接导线投影浓度。
3. **3. 左侧与底部按钮框**：
   - 未选中框底色/模糊度/描边与侧脊/字色、选中框渐变与高亮描边/侧脊/字色；
   - 新增 **按钮分层护边、投影与选中内收光** 参数：按钮黑护边色与浓度、待命框接触影浓度、选中框抬升下沉影浓度、选中框内收微光强度。
4. **4. 正文与页脚文字色**（默认折叠，点击展开）：主标题、正文段落、次要说明与注音、底部页脚字色。

### 4. 一键写入项目与导出备份

- **直接写入 `css/theme.css`**：在插件模式下，调色完毕直接点击底部绿色的 **「直接写入 css/theme.css」** 按钮，即可直接覆写仓库中的正式样式表 `css/theme.css`。
- **同步质感参数 / 复制导入 / 导出 CSS**：支持把模糊度、护边厚度与阴影浓度一键同步给其余作品页，也支持导出下载独立的 `theme.css` 或复制/导入 JSON 参数配置。
